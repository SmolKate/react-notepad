This project was performed using React + TypeScript + Vite.

# Run project

It is neseccary to perform the following command `npm run dev` in order to start the project in the development mode.

# Project target

This project was carried out for educational purposes. It was necessary to implement SPA that can save, delete and edit notes. It uses IndexedDb instead of data base and notes can include markdown syntax. Also it has authorization and registration pages. Thanks to this, this application can be used by different users.
